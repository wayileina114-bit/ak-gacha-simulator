# 明日方舟抽卡模拟器（Arknights Gacha Simulator）

一个单文件 HTML 的明日方舟抽卡模拟器，支持自选历史卡池、干员立绘、抽卡统计与皮肤图鉴。

## 功能特性

- 🎴 442 个历史卡池：限时寻访 / 标准寻访 / 中坚寻访 / 联合行动 / 定向甄选 / 中坚甄选 / 特殊卡池
- 🧑‍🚀 409 名干员：全部干员立绘（精二/初始）在线加载
- 🎨 皮肤图鉴：实时查询 bilibili Wiki，查看每位干员的全部皮肤（需联网）
- 🎯 保底与概率：6★ 2% 基础概率、50 抽后递增、100 抽必出；10 连必出 5★ 以上
- ⭐ 自选 UP：定向甄选 / 中坚甄选卡池可自选 UP 干员
- 📊 抽卡统计：欧气评分、六星间隔分布、每日出货、热力图、时段分析、保底总览
- 🏆 成就系统：10 项成就（含限定收藏家、全图鉴）
- 📱 手机端优化：抽屉式卡池选择、响应式布局
- 💾 数据导出：抽卡记录 CSV、卡池列表、存档导入导出
- ⌨️ 快捷键：1 单抽 / 2 十连 / 3 抽到6★ / ←/→ 切卡池 / F 收藏

## 使用方法

直接打开 抽卡模拟器.html 即可使用（需联网加载干员立绘与皮肤）。

## 数据来源

- 卡池/干员数据：PRTS Wiki（更新至 2026-08-29）
- 干员立绘/皮肤：bilibili Wiki
- 概率按官方规则模拟，仅供娱乐

## 本地构建

node build_all.js   读取 data/*.json 重新生成 抽卡模拟器.html
node fix_parser3.js （可选）从 PRTS 重新抓取卡池数据

## 技术说明

- 最终产物为单文件 HTML（约 337KB），数据内嵌于 script 标签
- 源码：app_part1.html（结构与样式）+ app_part2.js（全部逻辑）
- 数据：data/banners.json（卡池）+ data/ops_urls.json（干员与立绘）
